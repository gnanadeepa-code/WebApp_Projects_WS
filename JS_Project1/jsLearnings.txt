/*JavaScript Learnings*/

Data Types :
    1.String 
    2.Number 
    3.Boolean
    4.Undefined
let name = "John";     // String
let age = 25;          // Number
let isActive = true;   // Boolean
let x;                 // Undefined

typeof -> used to check the datatype
console.log(typeof "John");   // string
console.log(typeof 25);       // number
console.log(typeof true);     // boolean
console.log(typeof x);        // undefined

variable -> var is used when we use the item in more places, and when we change in one place all the other items which are referring to this variable will get updated 

Below 3 keywords are Used to declare variable :(use camelcase)

var name = "Alice";
let age = 20;
const city = "Chennai";

var -> Scope is Global. Reassignable. Redeclarable.
let -> Scope is block level. Reassignable. Not Redeclarable in same scope.
const -> Scope is block level.Not Reassignable. Not Redeclarable.

Arithmetic operators:
let a = 10;
let b = 5;

console.log(a + b); // 15
console.log(a - b); // 5
console.log(a * b); // 50
console.log(a / b); // 2
console.log(a % b); // 0

Comparison operators:
console.log(5 > 3);   // true
console.log(5 == 5);  // true
console.log(5 === "5"); // false . this is equal to operator
console.log(5 !== "5"); // true . this is not equal to operator

Conditionals:
Use if, else if, and else to make decisions.
let age = 18;

if (age >= 18) {
  console.log("You are an adult");
} else {
  console.log("You are a minor");
}

Loops ->Loops repeat code.

For loop:
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

While loop:
let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}
